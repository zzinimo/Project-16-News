# News Explorer

A news search and bookmarking application that lets users discover current news articles on any topic and save their favorites to a personal account.

## Technologies Used

- **React** - Component-based UI library
- **Vite** - Fast build tool and development server
- **React Router DOM** - Client-side routing
- **NewsAPI** - Third-party API for fetching news articles
- **CSS3** - Custom styling
- **ESLint** - Code linting
- **gh-pages** - GitHub Pages deployment

## How to Download

1. Clone the repository:

   ```bash
   git clone https://github.com/zzinimo/Project-16-News.git
   ```

2. Navigate to the Frontend directory:
   ```bash
   cd Project-16-News/Frontend
   ```

## How to Start

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. The app will automatically open in your default browser at `http://localhost:5173`

## How to Deploy

1. Build the production version:

   ```bash
   npm run build
   ```

2. Deploy to GitHub Pages:
   ```bash
   npm run deploy
   ```

The app will be deployed to your GitHub Pages URL.
